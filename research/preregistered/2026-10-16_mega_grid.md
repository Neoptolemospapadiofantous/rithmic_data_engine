# Pre-registration — mega grid of entries / stops / targets / exits (written 2026-10-16, BEFORE any run)

Founder: "test as many variants as possible". Big grids make lucky winners, so the grid is judged ONLY by these rules,
fixed now:

## Grids
1. **Cascade** (`grid_cascade`): first-check threshold k1 ∈ {0.15, 0.2, 0.25, 0.3, 0.35} × ATR, later checks
   k2 ∈ {0.2, 0.25, 0.3, 0.35}, stop ∈ {0.15, 0.2, 0.25, 0.35, 0.5} × ATR, target ∈ {none (flat 15:55), 1, 1.5, 2, 3, 4,
   5} R, break-even (stop to entry once price has gone 1R in favour) ∈ {off, on}, partial exit (half at 1R, the rest's
   stop to entry) ∈ {off, on} → 2,800 variants.
2. **Weak-day** (`grid_weak_day_*`): weakness IBS ≤ x ∈ {0.2, 0.3, 0.5}, VIX ≥ v ∈ {0, 15, 20, 25}, stop ∈ {none, 0.25,
   0.5, 1.0} × ATR, target ∈ {none, 1, 2, 3} R (with a stop), break-even ∈ {off, on}; entry 09:30; exit at 12:00, 14:00
   or 15:55 (three specs) → 3 × 384 variants (corrected before any run: 3 × 4 × 4 × 4 × 2 = 384).
## Judging (in this order; a grid only changes the fleet if ALL hold)
a. Walk-forward over all variants (edge_lab, normal gates; the report prints the t a best-of-N needs).
b. Frozen holdout, two splits (choose the best in-sample variant on 2010–18 → test once on 2019–22; on 2010–22 → test on
   2023–26). The grid's pick must beat the CURRENT fleet setting (cascade k1 0.25 / k2 0.3 / stop 0.25 / 2R; weak-day
   IBS ≤ 0.3 [edge_lab analog of the fleet's any-weakness rule], VIX ≥ 20, no stop, 15:55) on the same holdout window in BOTH splits.
c. Plateau: the mean holdout result of the dev top-10 must also beat the current setting (a single lucky variant can't).
Otherwise the fleet keeps its settings; the grid is recorded either way.

## Results (appended after the runs — rules unchanged)
**a. Walk-forward over all variants** (net pts/trade on unseen months): cascade 2,800 variants **+4.08** (FAIL controls:
random time 41 %, day 91 %) — WORSE than the original 54-variant cascade grid (+4.80); weak-day exit 15:55 +8.05 (PASS,
vs +13.2 for the original 12-variant grid), 14:00 +2.89 and 12:00 +1.62 (FAIL controls). Bigger grids = noisier
monthly picks.

**b/c. Frozen holdout** (pick and dev top-10 chosen on the dev window only, tested once):
| grid | split | dev pick → holdout | dev top-10 → holdout | current setting → holdout | variants positive on holdout |
|---|---|---|---|---|---|
| cascade | A (→ 2019–22) | k1 0.3 k2 0.3 no target stop 0.2: +7.37 (630) | +6.95 | +5.28 (662) | 100 % |
| cascade | B (→ 2023–26) | k1 0.3 k2 0.3 4R stop 0.25: +7.64 (524) | +8.54 | **+8.66** (540) | 100 % |
| weak-day 15:55 | A | VIX ≥ 25, IBS ≤ 0.2: +46.76 (81) | +42.54 | +25.68 (191) | 99 % |
| weak-day 15:55 | B | VIX ≥ 25, IBS ≤ 0.3: +250.64 (11) | +254.62 | +100.71 (56) | 69 % |
| weak-day 14:00 | A / B | +8.06 (250) / +250.52 (11) | +7.26 / +246.60 | +9.62 / +93.74 | 86 % / 66 % |
| weak-day 12:00 | A / B | +3.55 (152) / +73.95 (11) | +6.43 / +78.22 | +10.90 / +47.74 | 88 % / 47 % |
(Variants with no stop ignore break-even / target, so several labels are the same trade.)

**Verdict.** Cascade: the grid does NOT beat the current setting in both splits → the fleet keeps k1 0.25 / k2 0.3 /
stop 0.25 / 2R. Every one of the 2,800 variants was positive in both holdouts — the edge does not depend on the setting.
Weak-day 15:55: the pick (VIX ≥ 25 only) passes b/c per trade, but trades a fraction as often and makes LESS in total
(2019–22 ≈ 3,790 vs 4,905 pts; 2023–26 ≈ 2,757 vs 5,640 pts on 11 trades) — not adopted as a replacement; it confirms
the fleet's existing sizing (1 MNQ, +1 at VIX ≥ 25). Weak-day exits before 15:55 fail. No fleet change.
